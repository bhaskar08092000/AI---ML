1. Install Anaconda:
	Download anaconda distribution
	Install Anaconda
	This will create a 'base' environment
2. Create a new environment:
	conda create --name nitw
3. Create a clone of a any other environment:
	conda create --name tce --clone base
4. When you want to use a particular environment, activate that environment:
	conda activate nitw
5. Install the ipython kernel for the new environment
	ipython kernel install --user --name=nitw
6. Add any other python packages:
	conda install -c conda-forge wikipedia
	conda install -c conda-forge tweepy
7. Deactivate the environment (will return to base)
	conda deactivate
8. Remove an environment
	conda remove --name myenv --all
9. Register the kernel for environment 'ap':
	ipython kernel install --user --name=ap
10. Create an environment with a particular version of python
	conda create -n myenv python=3.9
	
	
How do I remove a Jupyter kernel?
	This may be necessary after removing the environment. The kernel still shows up in the Jupyter Lab and Jupyter NOtebook

1. At the conda prompt, list all the kernels with their paths:
	jupyter kernelspec list
2. Remove the unwanted kernel:
	jupyter kernelspec uninstall "unwanted-kernel"
